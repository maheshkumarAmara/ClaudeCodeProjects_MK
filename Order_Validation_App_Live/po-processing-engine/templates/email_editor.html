The PDF is read on the server and is not stored. The new addresses are written exactly as you type them; the sandbox.com rule used on the PO pages is not applied here. Replacement text is drawn in Helvetica, squeezed to the width of the address it replaces, so a much longer address will look narrower. Scanned PDFs with no text layer have no addresses to find.

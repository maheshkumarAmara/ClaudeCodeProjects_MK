How to Use This EDI Generator

Supports: Arrow, Carahsoft, Ingram, Exclusive Networks (UK)

  1. Select Vendor: Choose the distributor from the "Vendor Name" dropdown. The form will adjust defaults automatically:
    • Arrow / Carahsoft: PO Number max 6 digits.
    • Ingram: PO Number max 5 digits. Enables the "Merge EDI Files" button.
    • Exclusive Networks (UK): Uses tilde (~) delimiter format.
  2. Enter Key Information: Fill in the required fields marked with a red asterisk (*):
    • PO Number (hover the ⓘ next to the PO Number field for the format hint specific to your selected vendor)
    • End User PO Number (max 10 characters)
    • Quote Number
  3. Optional Fields:
    • Payment Terms: Select from dropdown (15, 30, 45, 60, 90) or auto-populated from Excel data.
    • CRSD (Customer Required Ship Date): Set the date if needed, or leave blank to omit from EDI.
    • Note on Contingency: Set to "Yes" to include special language acceptance in the EDI output.
  4. Salesforce Connection (New): The tool can now fetch line item data directly from Salesforce via the built-in bridge server.
    • Check the status indicator in the top-right corner — ● green = connected, ● red = offline.
    • If offline, click "Setup Guide" and follow the steps to start the bridge server (node sf-bridge-server.js) from your terminal.
    • Use the org selector (top-right) to switch between QA (rbkqa) and UAT (uat-org) — a warning banner appears when UAT is selected.
    • If you see "Session expired", run the re-login command shown in the Setup Guide for your org, then click "Refresh".
  5. Get Line Item Data — choose one method:
    • Method A — Fetch from Salesforce (Recommended): Enter your Quote Number, then click "Fetch from Salesforce" in the Quote Line Items section. Data is retrieved and populated automatically in one click. Requires the bridge server to be running.
    • Method B — Manual SOQL: Click "Copy SOQL" to copy the pre-built query (supports comma-separated quote numbers for Ingram multi-quote orders). Run it in Salesforce, paste the results into the Quote Line Items text area, then click "Parse Excel & Populate".
  6. Parse Excel & Populate: If using Method B above, click "Parse Excel & Populate". This will automatically fill in:
    • Line items table with Product ID, Description, Quantity, Price, and Subscription Term.
    • Contract Manufacturer and Payment Terms.
    • Address table: End User (EN) name and Bill-To (BT) distributor name.
  7. Split/Merge Quote Line Items:
    • -PA products (Dual Split): For items ending in "-PA" with term > 1, two buttons appear: T+ (Term Split — splits by subscription term with pro-rated prices) and Q+ (Quantity Split — splits by quantity, unit price unchanged). Choose based on your scenario.
    • -PM products (Dual Split): For items ending in "-PM" with term > 1, two buttons appear: T+ (Term Split — splits by subscription term with pro-rated prices) and Q+ (Quantity Split — splits by quantity, unit price unchanged). Choose based on your scenario.
    • Hover over the (+) button to see remaining term/quantity available for splitting.
  8. Delete a Line Item: Click the red (X) button in the "Actions" column to remove a row.
  9. Review Data: Verify the "Address Details Information" and "Quote Line Items" sections. The Address Details Information table is collapsed by default — click "Expand" above it to view or edit the address rows. All table columns are resizable by dragging the column header borders.
  10. Split Into Multiple POs (Optional):
    • Click "Add PO" to create additional PO tables.
    • Drag & Drop: Drag rows from one PO table to another.
    • Checkbox + Move Selected: Use the checkboxes (visible when multiple POs exist) to select rows, then click "Move Selected" to move them in bulk. Use "Select All" in the header to toggle all rows.
    • Click "Remove PO" to delete the last PO table (its items move back to PO 1).
    • At least one product must remain in each source PO.
  11. Generate EDI: Click "Generate EDI File". For multi-PO setups, you’ll be prompted to select which PO to generate and provide a unique PO number for each.
  12. Merge EDI Files (Ingram only): Click "Merge EDI Files" to combine multiple .edi/.txt files into a single merged EDI with sequential transaction set control numbers.
  13. Validate Your EDI: Click "EDI Validator" to check for ISA/IEA envelope integrity, control number mismatches, and segment count errors.
  14. Save Your File: Use "Copy to Clipboard" or "Download EDI File". Download filenames are auto-generated based on vendor, PO number, and timestamp.
  15. Refresh: Click "Refresh" to reset all fields and start fresh.

How to Use — Entitlement Links SR

  1. Start the Bridge Server
    In Terminal, navigate to the tool folder and run node sf-bridge-server.js. Keep this window open — all "Fetch" buttons require it.
    • Check the status indicator in the top-right — ● green = connected, ● red = offline.
    • Use the org selector (top-right) to switch between QA (rbkqa) and UAT (uat-org). A warning banner appears when UAT is selected.
    • If you see "Session expired", run the re-login command from the Setup Guide for your org, then click "Refresh".
  2. Fill Order Numbers — Quick Method (Recommended)
    Enter a Quote Number (e.g. Q-846992) and click "Fetch". This automatically:
    • Populates New Replacement Order Number(s) from the quote's OrderItems.
    • Populates Original Order Number(s) by reading Previous_Transaction_Reference__c from those orders — both fields filled in one click.
  3. Fill Order Numbers — Manual Method
    Type New Replacement Order Number(s) directly (comma-separated). Then click "Auto-fill" next to Original Order Number(s) to fetch the originals automatically from Salesforce.
  4. Load ContractLineItem Data
    In the Line Items section, click "Fetch from Salesforce" to pull data directly via the bridge.
    Or click "Copy SOQL", run it in Salesforce, paste the results, and click "Parse Excel & Populate".
  5. Fetch & Visualize Entitlement Links
    In the ContractLineItem Details section, click "Fetch Entitlement Links" — this fetches and visualizes in one step.
    Or click "Copy SOQL", run it in Salesforce, paste the JSON into the Entitlement Links JSON area, and click "Visualize".
  6. Copy & Compare JSON
    After visualization, two additional buttons are available in the Entitlement Links area:
    • Copy JSON: Copies the current Entitlement Links JSON to your clipboard.
    • Compare JSON: Opens a side-by-side comparison modal showing the Original JSON (as pasted/fetched) vs. After Visualize (the processed/cleaned output). Useful for reviewing any transformations applied during visualization.
  7. Interact with the Graph
    • Pan: click and drag the canvas.
    • Zoom: scroll wheel, or use the + / − / reset controls.
    • Card details: click any entitlement card to see full details (Status, Quantity, Order, Phantom Order, Term, etc.) in the Details panel.
    • Link labels: connector lines are colour-coded — grey = Renewal, blue = Conversion, green = Split-Surviving, red = Split-Conversion.

Salesforce Bridge — Setup Guide

Run once before using "Fetch from Salesforce" in any module

  1. 1

    Open Terminal

    Mac: press ⌘ Space → type Terminal → Enter

    Windows: press Win + R → type cmd → Enter

  2. 2

    Navigate to the tool folder

    cd ~/Documents/EDI_850_Implementation/Distributor
  3. 3

    Start the bridge server

    node sf-bridge-server.js

    Keep this Terminal window open while using the tool

  4. 4

    Come back here and click Refresh

    The status in the top-right should turn green — "SF Connected"

⚠ Session Expired? (Run when needed)

If you see "Session expired" when fetching from Salesforce, your login token has expired. Run the command for your org in a new terminal tab — no need to stop the bridge server:

QA Org

sf org login device --alias qa-org --instance-url https://rubrikinc--rbkqa.sandbox.my.salesforce.com

UAT Org

sf org login device --alias uat-org --instance-url https://rubrikinc--rbkuat.sandbox.my.salesforce.com

Follow the terminal prompts to log in → then retry your fetch.
